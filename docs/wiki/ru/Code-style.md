# Стандарт кода

Код пишется для людей, которые будут поддерживать его через год, не зная контекста. Стандарт
обязателен для каждого изменения; коротко:

- логика живёт в своём слое: форматы Amnezia — в `amnezia_core/`, SSH — в фоновых операциях,
  бизнес-правила — в сервисах, представления тонкие;
- класс заводится, когда хранит состояние или прячет решение, а не ради класса;
- строки интерфейса — через gettext (RU и EN);
- секреты и ресурсы, которые посещают пользователи VPN, никогда не логируются;
- изменилось поведение или настройки → `docs/wiki/` (RU и EN) и `CHANGELOG.md` в том же изменении;
- перед коммитом: `ruff check`, `ruff format --check`, `mypy`, `pytest`.

Полный текст — [docs/CODE_STYLE.md](../../CODE_STYLE.md).
