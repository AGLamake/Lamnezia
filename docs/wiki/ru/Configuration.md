# Настройка

Панель берёт настройки из переменных окружения с префиксом `LAMNEZIA_`, обычно из файла `.env`
(пример — `.env.example`). Настройки безопасности объяснены в
[Безопасность](Security.md).

В docker compose `LAMNEZIA_ALLOWED_HOSTS`, `LAMNEZIA_DATABASE_URL` и `LAMNEZIA_REDIS_URL`
выставляются сами из домена и пароля базы. После изменения `.env`: `docker compose up -d`.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `LAMNEZIA_SECRET_KEY` | — (обязательна) | Секретный ключ Django: длинная случайная строка. |
| `LAMNEZIA_DEBUG` | `False` | Режим отладки, только для локальной разработки. |
| `LAMNEZIA_ALLOWED_HOSTS` | пусто | Имена хостов панели через запятую. |
| `LAMNEZIA_DATABASE_URL` | SQLite `db.sqlite3` | Адрес базы, например `postgres://user:pass@host:5432/lamnezia`. |
| `LAMNEZIA_TIME_ZONE` | `UTC` | Часовой пояс дат в интерфейсе. |
| `LAMNEZIA_DOMAIN` | — (обязательна для compose) | Домен панели. |
| `LAMNEZIA_DB_PASSWORD` | — (обязательна для compose) | Пароль PostgreSQL, только буквы и цифры. |
| `LAMNEZIA_WEB_WORKERS` | `2` | Число процессов web. |
| `LAMNEZIA_POLL_WORKERS` | `2` | Число одновременных опросов серверов (мониторинг и трафик) в сервисе `poller`. |
| `LAMNEZIA_HTTP_BIND` | `127.0.0.1:8000` | Адрес, на котором web доступен для nginx сервера. |
| `LAMNEZIA_TRUSTED_PROXIES` | loopback и частные сети | Адреса или сети через запятую, чьи `X-Forwarded-For` и `X-Forwarded-Proto` панель читает; от остальных заголовки отбрасываются ([Безопасность](Security.md)). |
| `LAMNEZIA_IMAGE` | `lamnezia:latest` (локальная сборка) | Готовый образ, например `ghcr.io/aglamake/lamnezia:1.2.0` ([установка](Installation.md#готовый-образ-вместо-сборки)). |
| `LAMNEZIA_REDIS_URL` | пусто | Redis для WebSocket, фоновых задач и кэша. |
| `LAMNEZIA_ENCRYPTION_KEY` | — (обязательна) | Ключ шифрования SSH-доступов и приватных ключей в базе. На время смены ключа — несколько через запятую, шифрует первый ([Смена ключа шифрования](Security.md#смена-ключа-шифрования)). |
| `LAMNEZIA_SSH_CONNECT_TIMEOUT` | `15` | Секунд на подключение и вход на сервер. |
| `LAMNEZIA_SSH_COMMAND_TIMEOUT` | `120` | Секунд на одну команду на сервере. |
| `LAMNEZIA_SSH_LOCK_TIMEOUT` | `300` | Секунд ожидания, пока тот же сервер изменяет другая операция. |
| `LAMNEZIA_TRAFFIC_INTERVAL` | `300` | Секунд между чтениями трафика с серверов; с той же частотой применяются лимиты ([Пользователи, тарифы и лимиты](Users-plans-limits.md#применение-лимитов)). |
| `LAMNEZIA_RECONCILE_INTERVAL` | `900` | Секунд между сверками ключей панели с серверами. |
| `LAMNEZIA_GROUP_CATCH_UP_INTERVAL` | `300` | Секунд между проверками отстающих участников групп серверов и их догоном ([Группы серверов](Servers-and-import.md#группы-серверов)). |
| `LAMNEZIA_RELAY_SYNC_INTERVAL` | `60` | Секунд между проверками ретрансляторов; ретранслятор, у групп или участников которого что-то изменилось, обновляется ([Ретранслятор](Servers-and-import.md#ретранслятор)). |
| `LAMNEZIA_PROTOCOL_BACKUP_INTERVAL` | `3600` | Секунд между копиями файлов серверов (`awg0.conf`, `clientsTable`) в панель ([Бэкапы](Backup.md#копии-файлов-серверов)). |
| `LAMNEZIA_BACKUP_INTERVAL` | `86400` | Секунд между бэкапами базы и загруженных файлов. |
| `LAMNEZIA_BACKUP_KEEP` | `14` | Сколько бэкапов каждого вида хранить. |
| `LAMNEZIA_BACKUP_DIR` | `./backups` | Каталог для бэкапов на хосте. |
| `LAMNEZIA_MONITOR_INTERVAL` | `60` | Секунд между замерами состояния серверов. Сервер, не отвечающий два интервала, показывается офлайн. |
| `LAMNEZIA_METRICS_TOKEN` | пусто | Токен эндпоинта Prometheus `/metrics`. Пусто — эндпоинт выключен. |
| `LAMNEZIA_OPERATION_TIMEOUT` | `3600` | Секунд, после которых ждущая или выполняемая операция считается прерванной. |
| `LAMNEZIA_MONITOR_HISTORY_DAYS` | `7` | Сколько дней хранятся замеры состояния серверов. |
| `LAMNEZIA_MONITOR_DETAIL_DAYS` | `1` | Сколько дней замеры хранятся полностью; в более старых целых днях остаётся один замер на четверть часа. |
| `LAMNEZIA_OPERATION_RETENTION_DAYS` | `90` | Сколько дней завершённая операция хранится в журнале. |
| `LAMNEZIA_NOTIFICATION_RETENTION_DAYS` | `90` | Сколько дней отправленная или неудавшаяся доставка уведомления хранится в журнале. |
| `LAMNEZIA_TRAFFIC_HOURLY_DAYS` | `35` | Сколько дней трафик хранится по часам; более старые часы сворачиваются в одну запись на ключ и день (не меньше 1). Итоги, статистика и лимиты не меняются. |
| `LAMNEZIA_GITHUB_TOKEN` | пусто | Токен GitHub без прав. Повышает лимит API для ссылок на релизы Amnezia. |
| `LAMNEZIA_AMNEZIA_APP_STORE_URL` | Amnezia в App Store | Ссылка для iOS в инструкциях. |
| `LAMNEZIA_AMNEZIA_GOOGLE_PLAY_URL` | Amnezia в Google Play | Ссылка на Google Play в инструкциях. |
| `LAMNEZIA_REQUIRE_ADMIN_2FA` | `True` | Администраторы входят с кодом из приложения-аутентификатора. |
| `LAMNEZIA_LOGIN_FAILURE_LIMIT` | `5` | Сколько неверных паролей подряд, прежде чем вход в учётную запись с одного адреса приостановится. |
| `LAMNEZIA_LOGIN_LOCKOUT_MINUTES` | `15` | На сколько минут вход приостанавливается. |
| `LAMNEZIA_REGISTRATION_RATE_LIMIT` | `5` | Сколько открытых регистраций в час принимается с одного адреса. `0` снимает ограничение. |
| `LAMNEZIA_MAGIC_LINK_MINUTES` | `15` | Сколько минут работает ссылка для входа из письма. |
| `LAMNEZIA_SUBSCRIPTION_RATE_LIMIT` | `30` | Сколько раз в минуту с одного адреса можно запросить ссылку-подписку; сверх этого — ответ `429`. `0` снимает ограничение. |
| `LAMNEZIA_SUPPORT_RATE_LIMIT` | `5` | Сколько новых обращений в поддержку в час принимается от одного пользователя. `0` снимает ограничение. |
| `LAMNEZIA_SUPPORT_MESSAGE_RATE_LIMIT` | `10` | Сколько сообщений в минуту принимается от одного пользователя в чате и обращениях. `0` снимает ограничение. |
| `LAMNEZIA_SUGGESTION_RATE_LIMIT` | `3` | Сколько предложений статей в сутки принимается от одного пользователя ([Инструкции](Guides-and-releases.md#предложения-пользователей)). `0` снимает ограничение. |
| `LAMNEZIA_SUPPORT_INCIDENT_WINDOW_MINUTES` | `30` | Сообщения «не работает сервер», пришедшие не дальше этого друг от друга, собираются в один инцидент. |
| `LAMNEZIA_SITE_URL` | `https://<LAMNEZIA_DOMAIN>` | Адрес панели для ссылок, которые присылают боты. |
| `LAMNEZIA_BOT_RATE_LIMIT` | `20` | Команд в минуту, которые боты принимают от одного аккаунта мессенджера. `0` отключает ограничение. |
| `LAMNEZIA_TELEGRAM_WEBHOOK` | `false` | Telegram-бот получает обновления через webhook по адресу `<LAMNEZIA_SITE_URL>/bots/telegram/`, а не long polling. Нужен публичный домен с HTTPS ([Аккаунты Telegram и Discord](Messengers.md)). |
| `LAMNEZIA_EMAIL_URL` | `consolemail://` | Почтовый сервер для писем (сброс пароля, подтверждение email, ссылки для входа), например `smtp+tls://user:password@smtp.example.com:587`. По умолчанию письма только пишутся в лог `web`. |
| `LAMNEZIA_DEFAULT_FROM_EMAIL` | `Lamnezia <noreply@localhost>` | Отправитель писем. |
| `LAMNEZIA_PLUGINS` | пусто | Django-приложения через запятую, которые добавляются в панель, например плагины оплаты ([Плагины оплаты](Billing-plugins.md)). |
| `LAMNEZIA_HSTS_SECONDS` | `31536000` (`0` при `DEBUG`) | Срок HSTS: браузеры открывают панель только по HTTPS. `0` выключает HSTS. |

## Настройки панели

Настройки, которые меняются без перезапуска, — в разделе **Настройки** (`/settings/`, только
администраторы). Они хранятся в базе (модель `SiteSettings`, одна строка).

| Поле | По умолчанию | Назначение |
|---|---|---|
| Название панели | `Lamnezia` | Название в меню и заголовках страниц. |
| Регистрация | Только по приглашению | Только по приглашению, открытая с автоматическим одобрением или открытая с одобрением администратора ([Режимы регистрации](Registration-modes.md)). |
| Тариф по умолчанию | нет | Тариф новых пользователей открытой регистрации с автоматическим одобрением. |
| Подтверждение email при регистрации | включено | Открытая регистрация отправляет ссылку для подтверждения, если почта настроена. |
| Повторный показ ключа | В любое время | В любое время или только один раз: после первого показа ключ можно только перевыпустить ([Ключи](Keys.md#показ-ключа)). |
| Ключи в ботах | Сам ключ | Сам ключ или только ссылка на портал: чаты Telegram и Discord не защищены сквозным шифрованием ([Мессенджеры](Messengers.md#боты)). |
| Пользователи предлагают статьи | Включено | Вошедшие пользователи присылают ссылки и тексты для инструкций; выключение скрывает форму ([Инструкции](Guides-and-releases.md#предложения-пользователей)). |
| SMTP-сервер, порт, шифрование | пусто, `587`, STARTTLS | Почтовый сервер для писем; шифрование STARTTLS, SSL/TLS или без него. Пока сервер не задан, панель отправляет почту через `LAMNEZIA_EMAIL_URL`. |
| Пользователь SMTP, пароль SMTP | пусто | Логин на почтовом сервере. |
| Отправитель | пусто | `From` писем; если пусто — `LAMNEZIA_DEFAULT_FROM_EMAIL`. |
| Токен Telegram-бота | пусто | Бот для Telegram-каналов [уведомлений](Notifications.md), у которых нет своего токена, и для привязки Telegram. |
| Имя Telegram-бота | пусто | Без `@`; вместе с токеном пользователи могут [привязать Telegram](Messengers.md). |
| Вход через Telegram | выключен | Пользователи с привязанным Telegram входят через него; нужен `/setdomain` в @BotFather ([Мессенджеры](Messengers.md)). |
| ID приложения Discord, секрет клиента Discord | пусто | Приложение Discord OAuth2 для [привязки Discord](Messengers.md). |
| Токен Discord-бота | пусто | [Discord-бот](Messengers.md#discord-бот) и уведомления в личные сообщения Discord. |
| Вход через Discord | выключен | Пользователи с привязанным Discord входят через Discord. |
| Токен GitHub | пусто | Заменяет `LAMNEZIA_GITHUB_TOKEN` для ссылок на релизы Amnezia. |

Пароли и токены хранятся зашифрованными и больше не показываются: оставьте поле пустым, чтобы
сохранить прежнее значение, или отметьте **Удалить сохранённое значение**.

## Язык интерфейса

Интерфейс есть на русском и английском. Переключатель RU/EN — рядом с переключателем темы.
Пока пользователь язык не выбрал, панель берёт его из настроек браузера, иначе — русский.
Выбор хранится в cookie `django_language`; у вошедшего пользователя он становится и языком его
уведомлений (см. [Уведомления](Notifications.md)).
