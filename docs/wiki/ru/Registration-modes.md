# Регистрация и инвайты

Как новые пользователи попадают в панель, задаётся в **Настройки → Регистрация**.

| Режим | Что происходит |
|---|---|
| Только по приглашению (по умолчанию) | Страница **Зарегистрироваться** открывается только по ссылке инвайта. |
| Открытая, допуск автоматически | Зарегистрироваться может любой, и он сразу получает **тариф по умолчанию** из настроек. Если тариф по умолчанию не выбран, пользователь остаётся без тарифа, пока его не назначит администратор. |
| Открытая, с одобрением администратора | Новый пользователь входит, но ждёт: ключей нет, а портал сообщает, что аккаунт ждёт подтверждения. Администраторам с email приходит письмо. |

Очередь — в **Админка → Регистрация**: **Подтвердить** выдаёт выбранный тариф и открывает доступ,
**Отклонить** блокирует аккаунт.

## Инвайты

Инвайт — ссылка `https://<панель>/accounts/invite/<код>/`, которая создаётся в
**Админка → Регистрация**. У него есть тариф, число регистраций и, если нужно, срок действия. Инвайт
работает в любом режиме: пользователь сразу получает тариф инвайта (он важнее тарифа по
умолчанию), минуя очередь; email подтверждается так же, как при открытой регистрации. Истёкший или израсходованный инвайт регистрацию не
открывает.

Модератор тоже создаёт инвайты в **Регистрации** и видит только свои. Пользователь, пришедший по
инвайту модератора, сразу попадает в его [зону](Security.md#зона-модератора); если квота
пользователей модератора исчерпана, инвайт отвечает «По этому инвайту сейчас нельзя
зарегистрироваться.».

## Подтверждение email

Если включено **Подтверждение email** и настроена почта (SMTP-сервер в настройках или
`LAMNEZIA_EMAIL_URL`, отличный от консоли), любая регистрация, и по инвайту тоже, присылает ссылку
для подтверждения:
пока её не открыли, аккаунт неактивен. В режиме с одобрением администраторы узнают о заявке только
после подтверждения email. Без почты подтверждение не запрашивается.

## Ограничение по адресу

Открытая регистрация принимает не больше `LAMNEZIA_REGISTRATION_RATE_LIMIT` аккаунтов в час с одного
IP-адреса (по умолчанию `5`, `0` снимает ограничение). Регистрации по инвайту не считаются.

## Вход по ссылке на email

Когда почта настроена, на странице входа есть **Войти по ссылке на email**: панель присылает ссылку
для входа без пароля. Ссылка живёт `LAMNEZIA_MAGIC_LINK_MINUTES` минут (по умолчанию `15`) и работает
один раз. Ответ одинаковый, есть ли аккаунт с таким email или нет.
