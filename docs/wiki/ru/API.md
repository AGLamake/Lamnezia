# API

API панели даёт вашему биллингу, ботам и мониторингу читать данные панели: серверы и их состояние,
пользователей с лимитами и расходом, ключи и трафик, а с правом управления — выдавать и отзывать
ключи, продлевать доступ и менять тариф.

## Токены

**Система → Токены API** (`/settings/api/`) — каждый сотрудник (администратор или модератор)
выпускает здесь токены себе и видит только свои. Администратор видит и может отключить токены всех.
У токена есть:

- **название** — кто им пользуется, например `monitoring`;
- **права** — что токену можно (ниже);
- необязательный **срок**.

Токен действует от имени того, кто его выпустил, и никогда не видит больше, чем этот человек:
токен администратора — всю панель, токен модератора — только его серверы, пользователей и ключи.
Зона берётся в момент вызова: если сервер или пользователь ушёл из зоны модератора, его токены
перестают их видеть.

Значение токена (`lmz_…`) показывается один раз, сразу после создания, — тогда его и скопируйте.
Панель хранит только хеш и первые символы, чтобы токены можно было различить в списке.

Токен перестаёт работать, если его отключили, если срок вышел или если владельца заблокировали или
он больше не администратор и не модератор. **Отключить** — необратимо: вместо этого создайте новый
токен.

## Права

Право — это ресурс, действие и, если нужно, один объект. Строки прав в конструкторе складываются;
нужна хотя бы одна. Конструктор начинается с одной строки, остальные добавляет **Добавить строку**.

| Ресурс | Действия | Объект |
|---|---|---|
| Серверы (`servers`) | чтение | сервер |
| Пользователи (`users`) | чтение, управление | пользователь |
| Ключи (`keys`) | чтение, управление | сервер, пользователь или ключ |
| Трафик (`traffic`) | чтение | сервер, пользователь или ключ |
| Статус операций (`operations`) | чтение | — |

- **Управление** включает чтение.
- **Без объекта** право действует на всю вашу зону. С объектом — только на него: право на ключи с
  сервером даёт ключи этого сервера, с пользователем — ключи этого пользователя.
- Конструктор предлагает только серверы, пользователей и ключи вашей зоны.
- Читать через API можно, только пока вы сами видите этот раздел в панели, управлять — пока
  управляете им: если вашей роли оставили в «Ключах» только просмотр, токен тоже не сможет менять
  ключи, а без раздела «Серверы» не прочитает серверы. Трафик следует разделу «Статистика»; статус
  своих операций токен видит без раздела.
- Токены, созданные до версии с правами, получили чтение всех ресурсов без объекта — их доступ
  не изменился.

## Запрос

Токен передаётся в заголовке `Authorization`. В адресе панель его не принимает, чтобы он не попадал
в журналы прокси:

```sh
curl -H "Authorization: Bearer lmz_..." https://panel.example.com/api/v1/servers
```

Чтение — `GET`, изменения — `POST` с телом JSON:

```sh
curl -X POST -H "Authorization: Bearer lmz_..." -H "Content-Type: application/json" \
  -d '{"days": 30}' https://panel.example.com/api/v1/users/42/extend
```

Ответы — JSON, время в ISO 8601, трафик в байтах. Списки постраничные: `limit`
(по умолчанию 50, не больше 200) и `offset`; в ответе `count` (размер всего списка), `limit`,
`offset` и `results`.

Ошибки приходят как `{"error": {"code": "...", "message": "..."}}`:

| Код | `code` | Когда |
|---|---|---|
| 400 | `bad_parameter`, `bad_body` | У параметра запроса или поля тела неверное значение; тело не объект JSON. |
| 401 | `token_missing`, `token_invalid` | Нет токена, он неизвестен или не работает. |
| 403 | `forbidden` | Ни одно право токена не даёт этот ресурс и действие. |
| 404 | `not_found` | Объекта нет, он вне прав токена или вне зоны владельца. |
| 405 | `method_not_allowed` | Метод здесь не принимается; какие можно — в заголовке `Allow`. |
| 409 | `conflict` | Состояние не допускает изменения: ключ уже отзывается, у пользователя нет тарифа, лимит ключей исчерпан. |
| 429 | `too_many_calls` | Больше `LAMNEZIA_API_RATE_LIMIT` вызовов в минуту; подождите `Retry-After` секунд. |

## Эндпоинты

Все под `/api/v1/`:

| Путь | Что |
|---|---|
| `token` | Токен вызова: название, `scope` (`manage`, если хоть одно право управляет, иначе `read`), `permissions`, срок, владелец, `zone` (`whole` или `moderator`). |
| `servers`, `servers/<id>` | Состояние, онлайн, обслуживание, оплачен до, последний замер нагрузки, протоколы. |
| `users`, `users/<id>` | Роль, статус, тариф, модераторы (`moderator_ids`; `moderator_id` — первый из них), действующие лимиты и расход за период и всего. |
| `keys`, `keys/<id>` | Владелец, сервер, протокол, статус, даты. Фильтры: `user`, `server`, `status`. |
| `traffic` | Трафик по часам (`period=day`) или по дням (`week`, `month`) и по ключам. Фильтры: `server`, `user`, `key`. Если право на трафик дано с объектом, укажите его фильтром. |
| `operations/<id>` | Статус операции, запущенной этим токеном, или её повтора: `pending`, `running`, `succeeded`, `failed`, время и ошибка. |

Изменения (`POST`). Каждое сразу отвечает `202` и списком `operation_ids`: работа на сервере идёт
в фоне, её итог смотрите в `operations/<id>`.

| Путь | Тело | Что |
|---|---|---|
| `keys` | `source`, `user_id`, `name` | Выдать ключ пользователю на протоколе (`source` из `servers` → `protocols`); в ответе `key_id`. |
| `keys/<id>/revoke` | — | Отозвать ключ. |
| `users/<id>/extend` | `days` (1–3650) | Продлить доступ; в ответе новый `access_until`. |
| `users/<id>/plan` | `plan_id` | Перевести на тариф, который вы можете выдавать. |

Изменения через API попадают в журнал так же, как сделанные в панели, от имени владельца токена.

Полное описание — OpenAPI 3.1 по адресу `/api/v1/openapi.json`. Токен для него не нужен: данных
панели в нём нет. Его можно загрузить в Swagger UI, Postman или генератор клиентов.

## Чего API не отдаёт никогда

SSH-доступы к серверам, ключи серверов и настройки протоколов, приватные ключи и профили клиентов,
публичный ключ ключа (у XRay это UUID клиента — сам доступ), ссылки-подписки, пароли и данные 2FA.

## Частота и аудит

Один токен делает не больше `LAMNEZIA_API_RATE_LIMIT` вызовов в минуту (по умолчанию 120, `0`
снимает ограничение, [Настройка](Configuration.md)). Вызовы с неверным токеном ограничиваются так же,
но по адресу клиента, поэтому подбирать токены бесполезно.

Каждый вызов с рабочим токеном попадает в [журнал действий](Audit.md) как **Вызов API** с началом
токена, путём и кодом ответа. Вызов отключённым или просроченным токеном — **Вызов API отключённым
токеном**. Вызовы с неизвестными токенами не пишутся, чтобы перебор не засорял журнал. Создание и
отключение токена тоже пишутся. **События в журнале** у токена открывает журнал сразу с фильтром
по его началу. Записи **Вызов API** хранятся 30 дней (`LAMNEZIA_API_CALL_RETENTION_DAYS`,
[Настройка](Configuration.md)), более старые удаляются раз в сутки; сколько их, видно строкой в
**Статистика → Хранение**. Остальные записи журнала, в том числе вызовы отключённым токеном, не
удаляются.
