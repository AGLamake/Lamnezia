# Ключи

Ключ — это один клиент (пир) протокола на сервере. Ключами управляют в разделе **Ключи**
интерфейса администратора (`/keys/`, администраторы и модераторы; модератор — только в своей
[зоне](Security.md)).

## Выдача

**Выдать ключ**: выберите пользователя, сервер и протокол и имя устройства. Панель создаёт ключи
клиента, добавляет пира на сервер и записывает пользователя в `clientsTable`, поэтому ключ виден
и в приложении Amnezia. На странице операции виден ход выдачи; если она упала, нажмите
**Повторить**: тот же ключ будет добавлен снова, ничего не задвоится. Серверы на обслуживании для
новых ключей не предлагаются.

Приватный ключ клиента хранится зашифрованным ключом `LAMNEZIA_ENCRYPTION_KEY` вместе с
настройками сервера, нужными, чтобы показать ключ позже.

## Показ ключа

**Показать ключ** — ссылка `vpn://` для приложения Amnezia, QR-код (для больших конфигураций —
серия кодов) и файл `.conf` для приложения AmneziaWG; у ключа XRay вместо `.conf` — ссылка
`vless://` для других клиентов XRay, у ключа OpenVPN — файл `.ovpn`, а у ключа IPsec — файл `.sswan` для strongSwan на Android
и профиль `.mobileconfig` для iPhone, iPad и Mac. Каждый просмотр ключа администратором
записывается в журнал. **Разрешить владельцу открыть ещё раз** сбрасывает первый просмотр ключа
для политики «показать один раз».

Ключи, импортированные с сервера, созданы не панелью и не имеют приватной части: их нельзя
показать, только отозвать или перевыпустить. Исключение — импортированные ключи XRay: панель знает их
UUID, поэтому при первом открытии такого ключа она в фоне читает настройки сервера из `server.json`,
и через несколько секунд ключ можно показать; ключ в ссылке-подписке появляется в ней при одном из
следующих обновлений.

shortId Reality входит в каждый ключ XRay. Панель хранит тот, что последний раз прочитала из
`server.json`; если shortId на сервере сменился (например, протокол заново настроили в приложении
Amnezia), панель замечает это при следующей выдаче ключа или периодической проверке и обновляет
сохранённые профили — показанные после этого ключи получают новый.

## Другие действия

- **Отключить / Включить** — пир убирается из конфигурации сервера и возвращается с тем же адресом
  и ключами, поэтому конфигурация клиента продолжает работать.
- **Отозвать** — пир и его запись в `clientsTable` удаляются, панель забывает секреты.
  Пока операция идёт, ключ в статусе *отзывается*: он уже не занимает место в лимитах, а повторное
  **Отозвать** ничего не запускает.
- **Перевыпустить** — новый ключ для того же владельца, сервера и устройства одной операцией
  `keys.reissue`; старый ключ сразу *отзывается*. Если новый ключ сделать не удалось, старому
  возвращается прежний статус.
- **Передать пользователю** — для ключей без владельца (например, импортированных); владелец
  записывается и в `clientsTable` на сервере.

Каждое действие — фоновая операция, она видна в разделе **Операции**.

**Отключить**, **Включить** и **Отозвать** работают и для нескольких ключей сразу: отметьте их в
разделе **Ключи**, выберите действие над таблицей и нажмите **Применить**. На каждый ключ
запускается своя операция, и панель открывает **Операции**; ключи, статус которых не позволяет
действие, пропускаются и подсчитываются. Модератор может отметить только ключи своих
пользователей.

## Расхождения с серверами

Приложение Amnezia правит те же файлы, что и панель. Каждые `LAMNEZIA_RECONCILE_INTERVAL` секунд
(по умолчанию 15 минут) и по кнопке **Ключи → Расхождения с серверами → Проверить сейчас** панель
читает каждый сервер и сравнивает его со своими ключами. Чтение ничего не меняет на сервере.

| Расхождение | Что произошло | Действия |
|---|---|---|
| добавлен вне панели | клиента добавили в приложении Amnezia или вручную | **Добавить в панель** — ключ без владельца, как импортированный; **Удалить с сервера** |
| удалён вне панели | у активного ключа нет клиента на сервере | **Вернуть на сервер** — с тем же адресом, устройство продолжит работать; **Считать отозванным** |
| выключен в панели, но есть на сервере | отключённый или отозванный ключ остался на сервере | **Удалить с сервера**; **Считать активным** |

Перед действием панель снова читает сервер: если расхождения уже нет, ничего не меняется; если оно
стало другим, операция останавливается и просит проверить ещё раз. Каждое действие записывается в
журнал действий.

Источники с расхождениями показаны карточками с таблицей; совпадающие с панелью собраны в одну
короткую карточку — по строке на сервер и протокол с кнопкой **Проверить сейчас**.
