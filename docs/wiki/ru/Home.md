# Lamnezia

Self-hosted веб-панель для управления серверами Amnezia VPN: импорт серверов, настроенных в
приложении Amnezia, выдача ключей, тарифы и лимиты, статистика трафика, поддержка и клиентский
портал. Панель хранит файлы серверов в формате приложения Amnezia, поэтому приложение продолжает
работать с теми же серверами.

> Lamnezia — независимый проект и официально не связан с командой Amnezia VPN.
